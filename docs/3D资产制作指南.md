## 一、总体流程

```
形象设计图         3D模型化           骨骼动画            进App
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ Lovart /  │ →  │ Meshy /   │ →  │ Meshy     │ →  │ GLB文件   │
│ Midjourney│    │ Tripo3D   │    │ 自动绑骨   │    │ 放入项目  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
   出三视图        图生3D+贴图      待机+互动动画      3行配置接入
```

**分工**：第1~3步在浏览器完成（约30分钟/只）；第4步把文件发给 Claude 或放入 `public/models/` 即可，管线已就绪。

## 二、第1步：Lovart 生成形象设计图

### 通用风格前缀（每条提示词前都加上）

> 可爱萌宠3D角色设计，Q版圆润比例，皮克斯/迪士尼渲染风格，柔和打光，干净纯色背景，三视图（正面/侧面/背面），适合3D建模参考

### 三只萌宠的提示词

**团团（金毛犬 · 主题色琥珀橙 #d97706）**
> 一只2岁金毛寻回犬幼犬，蓬松的金黄色毛发，温暖的棕色大眼睛带高光，粉色小舌头微微吐出，尾巴上扬摇摆感，坐姿憨态可掬，忠诚热情的性格气质

**小雪（布偶猫 · 主题色紫罗兰 #7c3aed）**
> 一只3岁布偶猫，白色蓬松长毛带浅灰色重点色（耳朵/面部/尾巴），大大的蓝宝石色眼睛，粉色内耳和小鼻子，优雅端坐姿态，微微抬下巴的傲娇气质

**棉花糖（银狐仓鼠 · 主题色粉 #ec4899）**
> 一只1岁银狐仓鼠，纯白色毛发，超圆润球形身体，鼓鼓的粉色腮帮子像塞满了瓜子，黑豆眼带星星高光，小短爪捧在胸前，元气呆萌气质

### 出图要点
- ✅ 选**三视图**构图 —— 3D化的关键，单视角图生成的模型背面会崩
- ✅ 背景越干净越好（纯色/白色）
- ✅ 姿势选**站立或端坐的对称姿势**，避免趴卧、扭身等复杂姿势
- ❌ 避免复杂配饰（项圈丝带等细小物件3D化容易碎裂）

## 三、第2步：Meshy 图生3D

网址：[meshy.ai](https://meshy.ai)（注册送免费额度，够做完三只）
备选：[tripo3d.ai](https://tripo3d.ai)（质量相当，额度政策不同）

### 操作步骤
1. 登录后选择 **Image to 3D**
2. 上传 Lovart 生成的**正面图**（有多视角上传选项则把三视图都传）
3. 参数建议：
   - Topology：**Quad**（四边面，绑骨效果更好）
   - Target Polycount：**30k 以内**（手机端流畅）
   - Symmetry：**On**（宠物是对称的）
4. 生成后旋转检查：背面毛发是否完整、腿部是否粘连
5. 不满意就换一张设计图重试（AI生成有随机性，通常2~3次内出好结果）

### 质量自查清单
- [ ] 360°旋转无破面、无穿模
- [ ] 眼睛清晰有神（最重要！眼睛崩了萌感全无）
- [ ] 四肢分离清楚，没有粘在身体上
- [ ] 贴图颜色和设计图一致

## 四、第3步：自动绑骨 + 动画

在 Meshy 模型详情页选择 **Animate**：

1. **Auto-rigging**：选 **四足动物（Quadruped）** 模板
   - 仓鼠这种球形身体如果绑四足失败，退而选 Biped 或跳过绑骨（见下方"静态模型备选方案"）
2. 挑选动画，每只**至少2个**：
   | 用途 | 推荐动画 | 对应App行为 |
   |------|---------|------------|
   | 待机 idle | Idle / Sit / Look Around | 平时站在主界面 |
   | 互动 hover | Jump / Run / Wag | 摸头、点击时播放 |
3. **Export → GLB格式**，务必勾选 **Include Animations**

### 静态模型备选方案
如果绑骨效果不好，**直接导出静态GLB也可以**——App的程序化动画系统（呼吸起伏、左右摇摆、开心弹跳）可以直接应用到静态模型上，效果同样生动。

## 五、第4步：接入App

### 方式一：发文件给 Claude（推荐）
把 `.glb` 文件发到对话里，说明是哪只宠物，剩下的交给 Claude：
- 自动检测动画片段名
- 调整缩放/位置/朝向适配舞台
- 配置待机/互动动画切换

### 方式二：自己动手
1. 文件放入 `public/models/`，命名如 `cat.glb`、`hamster.glb`
2. 查看模型的动画名：
   ```bash
   node -e "const b=require('fs').readFileSync('public/models/cat.glb'); console.log(JSON.parse(b.slice(20,20+b.readUInt32LE(12))).animations.map(a=>a.name))"
   ```
3. 在 `src/data/petModels.ts` 注册：
   ```ts
   xiaoxue: {
     url: '/models/cat.glb',
     scale: 1,            // 先用1，看效果再调
     yOffset: -0.65,      // 脚底贴地
     idleAnimation: 'Idle',   // 第2步查到的动画名
     hoverAnimation: 'Jump',
   },
   ```
4. `npm run dev` 查看效果，调 `scale` 直到大小合适

### 已就绪的技术设施
- ✅ GLB加载管线（`GLBPet.tsx`）：骨骼动画播放、待机/互动平滑切换、多画布实例化
- ✅ 模型注册表（`petModels.ts`）：每只宠物3行配置
- ✅ 自动回退：GLB缺失或加载失败时自动显示程序化卡通模型，App永不白屏

## 七、常见问题

**Q：Meshy 生成的模型太大/太小？**
A：不用管，接入时调 `scale` 参数即可。

**Q：模型颜色在App里看起来和 Meshy 里不一样？**
A：App使用ACES电影级色调映射+自定义灯光，Claude 接入时会调整材质参数匹配整体画风。

**Q：动画名是乱码或英文看不懂？**
A：发给 Claude，会自动检测并选择合适的动画。

**Q：想要更精细的模型（恋与深空级别）？**
A：AI生成是"高保真"级别；要到"顶级"需要委托专业美术（几千~几万元/只，含建模+绑定+动画），届时同样导出GLB接入，管线无需改动。
