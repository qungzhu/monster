# 毛茸伙伴 FurryPal - 产品需求文档 (PRD)

## 一、产品概述

### 1.1 产品名称
**毛茸伙伴 FurryPal**

### 1.2 产品定位
对标《恋与深空》的情感陪伴模式，以**萌宠**为核心角色的 AI 情绪价值陪伴型 App。用户可以与虚拟萌宠进行情感互动，获得陪伴、治愈和情绪疏导。

### 1.3 目标用户
| 用户群体 | 描述 |
|----------|------|
| Z世代年轻人 | 18-30岁，孤独感强，渴望陪伴但养宠受限（租房/时间/过敏等） |
| 情绪敏感型用户 | 有轻度焦虑、压力，需要安全的情感出口 |
| 萌宠爱好者 | 喜爱小动物，对拟人化萌宠有天然好感 |
| 养宠人群 | 已有宠物，但也享受虚拟萌宠的陪伴乐趣 |

### 1.4 核心价值主张
> "你的口袋里，住着一只懂你心情的小可爱。"

- **情绪价值**：萌宠用各自独特的方式感知用户情绪，提供个性化的情感回应
- **无负担陪伴**：不需要喂食、遛弯、清理，随时随地获得温暖
- **成长羁绊**：与萌宠建立越来越深的羁绊关系，解锁更多互动内容

## 四、核心功能模块

### 4.1 智能聊天系统（核心功能）

#### 功能描述
用户可以与选定的萌宠进行自然语言对话。系统通过**情绪关键词检测**识别用户当前情绪，萌宠给出个性化的情感回应。

#### 功能细节
| 特性 | 说明 |
|------|------|
| 情绪感知 | 基于关键词匹配检测6种情绪：开心、难过、生气、焦虑、孤单、平静 |
| 个性化回应 | 每只萌宠对同一情绪有不同风格的回应（团团热情安慰/小雪傲娇关心/棉花糖呆萌治愈） |
| 打字动画 | 萌宠"正在输入..."动画（1-3秒随机延迟，模拟真实感） |
| 时段问候 | 根据时间段（早/午/晚）自动发送不同的问候消息 |
| 心情快捷选择 | 用户可直接选择当前心情emoji，触发对应情绪回应 |
| 互动奖励 | 每次对话增加亲密度+2 |

#### 情绪关键词库示例
```
开心: 开心、高兴、快乐、哈哈、太棒、好开心、幸福、谢谢...
难过: 难过、伤心、哭、心痛、失落、沮丧、想哭、心碎...
生气: 生气、愤怒、烦死、讨厌、可恶、气死、受不了...
焦虑: 焦虑、紧张、担心、害怕、压力、崩溃、怎么办...
孤单: 孤独、孤单、寂寞、一个人、没人、想你、无聊...
```

#### 当前版本交互流程
```
用户输入消息 → 情绪关键词检测 → 匹配萌宠情绪回应库 → 随机选取回应 → 打字动画 → 显示回复
```

#### 未来版本演进
- v2.0：接入大语言模型（Claude API），实现真正的AI自由对话
- v2.5：增加语音消息，萌宠可发送语音回复
- v3.0：增加萌宠表情包/动态贴纸回复

### 4.2 亲密度成长系统

#### 功能描述
用户与萌宠的每次互动都会积累亲密度，亲密度提升会解锁更多互动内容和称号。

#### 亲密度等级
| 亲密度 | 称号 | 解锁内容 |
|--------|------|----------|
| 0-19 | 初见 | 基础对话 |
| 20-39 | 熟悉 | 更多日常对话选项 |
| 40-59 | 信任 | 萌宠主动分享日常（未来） |
| 60-79 | 依赖 | 专属互动动画（未来） |
| 80-100 | 最佳拍档 | 隐藏剧情/特殊回应（未来） |

#### 亲密度获取途径
| 行为 | 亲密度 |
|------|--------|
| 发送消息 | +2 |
| 摸摸头（爪印按钮） | +1 |
| 每日签到 | +5 |
| 记录心情日记 | +3 |

## 五、技术架构

### 5.1 当前技术栈（v1.0 已实现）
| 层级 | 技术 |
|------|------|
| 框架 | React 19 + TypeScript |
| 构建 | Vite 8 |
| 路由 | React Router DOM 7 |
| 样式 | Tailwind CSS 4 |
| 动画 | Framer Motion 12 |
| 图标 | Lucide React |
| 状态管理 | React Hooks (useState) + localStorage |
| AI对话 | 关键词匹配 + 预设回应模板 |

### 5.2 项目结构
```
src/
├── App.tsx                 # 主路由 + 布局
├── main.tsx                # 入口
├── index.css               # Tailwind + 主题 + 动画
├── data/
│   └── characters.ts       # 角色数据 + 类型定义
├── store/
│   └── useStore.ts         # 全局状态管理 (localStorage持久化)
├── utils/
│   └── emotion.ts          # 情绪关键词检测
├── components/
│   ├── Navigation.tsx       # 底部导航栏
│   ├── IntimacyBar.tsx      # 亲密度进度条
│   ├── TypingIndicator.tsx  # 打字动画
│   └── ParticleBackground.tsx # 粒子背景动画
├── pages/
│   ├── WelcomePage.tsx      # 首页/角色选择
│   ├── ChatPage.tsx         # 聊天界面
│   ├── ProfilePage.tsx      # 萌宠档案
│   ├── MoodPage.tsx         # 心情日记
│   └── SettingsPage.tsx     # 设置页
```

### 5.3 数据存储方案
**当前**：浏览器 localStorage（键值对前缀 `fp-`）
```
fp-selected-character    # 当前选中角色ID
fp-chat-history          # 聊天记录 (按角色分组)
fp-mood-entries          # 心情日记条目
fp-intimacy-levels       # 亲密度数值 (按角色)
fp-user-name             # 用户昵称
fp-checked-in            # 签到日期
```

**未来演进**：
- v2.0：接入后端API + 数据库（用户账号体系）
- v2.5：云端同步，多设备数据共享

## 六、UI/UX 设计规范

### 6.1 设计风格
- **整体风格**：深色主题 + 毛玻璃(Glassmorphism)
- **配色方案**：深紫灰底色(`#1a1025`)，每只萌宠独立主题渐变色
- **动效**：Framer Motion 页面过渡 + 消息弹入动画 + 粒子背景
- **字体**：Noto Sans SC（正文）+ Noto Serif SC（标题）

### 6.2 角色主题色
| 角色 | 主色 | 渐变 |
|------|------|------|
| 团团 | `#d97706` 琥珀 | 琥珀 → 金色 → 淡黄 |
| 小雪 | `#7c3aed` 紫 | 紫 → 薰衣草 → 浅紫 |
| 棉花糖 | `#ec4899` 粉 | 粉 → 桃 → 浅粉 |

### 6.3 页面布局
- 移动端优先设计（max-width 容器）
- 固定底部导航栏（5个Tab）
- 聊天页采用标准即时通讯布局（消息流 + 底部输入框）

## 十、风险与合规

| 用户情绪依赖 | App内提示"如有严重心理困扰请寻求专业帮助"；提供心理咨询热线链接 |
